# 邮件简报阅读版

`reading-v1` 使用同一模板生成本机留档、邮件附件和 Telegram 附件。

这是三种可选版面中的默认 `reading`。另外可选 `compact` 与 `print`，见[报告样板](report-templates.md)。

- 需要关注：本地分类标为高优先级或待回复的邮件。
- 可选决定：中优先级的客户、订单、账单或个人邮件。
- 兴趣资讯：购物、投资、房产、技术、游戏及其他动态，按主题折叠。
- 展开主题后保留每封邮件的完整脱敏摘要、分类、期限和邮件编号。
- 本人收件邮箱仅在 `show_own_addresses` 已启用时显示。
- 覆盖说明只显示数量，不展示本机保留的敏感邮件内容。

主题由已脱敏的标题和摘要匹配，不额外调用模型，不增加云端数据。
归类可能有误，应按需核对原邮件；程序不会因排版变化重新处理邮件。

文件不加载远程脚本、图片或字体。阅读控制只调整字号、外观和折叠状态，
设置尝试存入浏览器本地存储，不执行网络请求。固定控制脚本使用 SHA-256
CSP 校验，所有邮件文本均转义后插入页面。

手机若只显示 HTML 源码，可下载后选择浏览器打开；静态图片可作为版面预览。
